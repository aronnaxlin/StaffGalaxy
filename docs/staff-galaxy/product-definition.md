# Staff Galaxy Product Definition

## Working Name

**Staff Galaxy**

基于 Bangumi 数据的动画制作人员合作星图。

## One Sentence

以动画制作人员为星体，以共同参与作品为连线，探索动画业界中的合作关系、团队结构与职业轨迹。

## Product Position

Staff Galaxy 第一版不是动画推荐系统，也不是作品百科页。它的核心价值是把 Bangumi Archive 中的 STAFF 事实记录投影成人物合作网络，让用户能探索：

- 这个人和谁合作过
- 两个人是否共同参与过作品
- 他们合作过几次
- 双方分别担任什么职位
- 某个人最稳定的合作圈是谁
- 动画业界合作网络的大致星团结构是什么样

## Non Goals For MVP

MVP 不做这些事：

- 不推荐“下一部动画”
- 不把动画作品作为默认图节点
- 不爬 Bangumi 网页
- 不实时在浏览器里排布完整大图
- 不把全部 STAFF 直接两两投影后全量渲染
- 不按职位给人物永久上色
- 不预生成所有人物对详情文件

这些限制不是功能缩水，而是为了保护产品语义和工程规模。

## Core User Journey

```text
进入网站
→ 看到一张人物总星系
→ 搜索某个人
→ 定位并高亮其合作网络
→ 再搜索另一个人进行对比
→ 查看两者共同参与作品与职位
→ 点击邻居人物继续探索
```

## Product Semantics

### Default Node

默认图中的节点只表示真实个人：

```ts
type NodeType = "person";
```

Bangumi `Person.type` 中：

- `1`: 个人
- `2`: 公司
- `3`: 组合

MVP 只渲染 `type = 1` 的个人。公司与组合后续可以作为可切换图层加入，但不进入第一版默认图。

### Default Edge

默认图中的边表示两位人物至少共同参与过一部动画作品，并且这条边通过稀疏化规则被选中进入默认可见图。

重要区分：

- 默认图中没有边，不代表两个人没有共同作品
- 默认图中不可见的弱关系，仍然必须能通过双人搜索从证据层查出

### Evidence Layer

动画作品不作为默认节点出现，但不能从系统中消失。作品是人物关系的证据层：

```text
Person A ──[监督]────> Subject X
Person B ──[原画]────> Subject X
```

展示为：

```text
Person A ──[共同参与 Subject X]── Person B
```

侧栏必须能回溯到：

- 共同作品
- 作品年份
- A 的职位
- B 的职位
- 首次合作年份
- 最近合作年份

## Visual Direction

Staff Galaxy 应该像严肃的数据探索工具，而不是动漫周边网站。

默认视觉目标：

- 深色全屏星图
- 人物节点像星点
- 社区决定颜色
- 节点大小反映可见合作强度或可见连接数
- 选中与对比状态通过描边、标签和高亮表达
- 默认标签稀疏，搜索、悬停、点击、放大后逐步显示

## Key Product Principle

完整数据要保留，但不能全部画出来。

这条原则优先级高于“看起来更热闹”。如果全量 STAFF 两两连边，图会迅速变成不可读、不可交互、不可解释的噪声。

# MVP Acceptance Criteria

## Product Acceptance

- [x] 进入页面默认看到人物总星系。
- [x] 默认图中没有动画作品节点。
- [x] 所有可见节点都对应 Bangumi 中的真实个人。
- [x] 默认边表示共同参与动画作品。
- [x] 默认边可以展开查看作品证据。
- [x] 可以搜索并定位一个人。
- [x] 可以输入两个人进行路径查询（关系星图）。
- [x] 能显示两人共同参与过哪些动画（侧栏合作详情）。
- [x] 能显示双方在共同作品中的职位。
- [x] 隐藏于默认图的弱关系可以通过直接查询查出。
- [x] 全局图采用固定布局（deterministic spiral），不在首次加载时实时计算。
- [x] 有数据快照时间显示。
- [x] 有"Bangumi 记录可能不完整"的说明。

## Data Acceptance

- [x] 本地 Bangumi Archive 文件能被检测并导入。
- [x] `subjects` 只保留动画条目用于 STAFF 图分析。
- [x] `persons` 只保留真实个人用于默认图。
- [x] `credits` 保留原始职位文本。
- [x] 职位标准化模块能输出 role key、tier、weight。
- [x] 未映射职位会进入报告，而不是被静默丢弃。
- [x] 数据审计报告包含各 Tier 规模对比。
- [x] 默认图阈值来自真实审计数字。

## Graph Semantics Acceptance

- [x] 节点颜色为白色/灰色，高度数节点带暖色。
- [x] 节点大小反映可见加权度数。
- [x] 搜索人物有明显描边和常显标签。
- [x] 默认边稀疏，不渲染全量两两 STAFF 边。
- [x] 证据层完整保留所有职位关系。
- [x] 双人合作详情能发现默认图中不可见的弱关系。
- [x] 悬停节点显示名称并高亮邻居。
- [x] 点击节点打开详情侧栏。
- [x] 搜索结果能定位到节点并进入个人星系。
- [x] 六度理论验证页面（关系星图）显示两人间的最短路径。
- [x] 统一搜索支持简体中文、日文汉字、Bangumi ID。

## Frontend Acceptance

- [x] 初始加载使用固定坐标。
- [x] 初始标签稀疏，悬停显示。
- [x] 悬停节点显示名称（DOM 浮空标签，非 WebGL 文本）。
- [x] 点击节点打开详情侧栏，包含合作者列表。
- [x] 合作详情可展开显示共同作品及双方职位。
- [x] 个人星系有返回全局视图的按钮。
- [x] 默认全局标签（高优先级节点常显名称）。
- [ ] 底部筛选栏（职位层、时间范围、边强度）。
- [ ] 响应式/移动端布局。

## Performance Acceptance

- [x] 初始页面不执行完整大图力导向布局。
- [x] 初始页面不加载所有 person detail。
- [x] 大图渲染通过 zoom-dependent LOD 保持可交互。
- [x] Hover 使用 DOM 直控，不触发 React re-render。
- [x] Pixel ratio 封顶 2x。
- [x] Bundle splitting（延迟加载 Cosmos.gl）。
- [ ] 性能仪表盘（传输体积、解析时间、渲染时间）。

## Search Acceptance

- [x] 单一搜索框，无需选择搜索类型。
- [x] 支持 Bangumi 数字 ID 搜索。
- [x] 支持简体中文搜索（CJK 变体映射）。
- [x] 支持 Archive 已提供的繁体中文人物名搜索。
- [x] 支持日文汉字搜索。
- [x] 支持多词 AND 匹配。
- [x] 键盘导航（上下选择、回车确认、Esc 关闭）。
- [x] 选中后锁定为 pill，X 按钮或 Backspace 清除。

## Path Finding Acceptance

- [x] 独立的关系星图页面。
- [x] 两人各一个搜索框，锁定 pill 模式。
- [x] BFS 查找所有最短路径。
- [x] SVG 渲染路径，彩色贝塞尔曲线。
- [x] 节点按 BFS 深度分列排布。
- [x] 边标签显示共享作品数。
- [x] 悬停路径高亮，淡化其他路径。
- [x] 点击路径节点可跳转至该人物星系。
